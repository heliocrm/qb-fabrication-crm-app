# Cheat sheet — Traveler floor sign-off

**App:** Station tablet → Traveler / job Traveler tab · or `https://traveler.qbfab.com`  
**Full guide:** [User Guide § Travelers](./user-guide.md)  
**Office import / print:** managers & members import the WO PDF on the job; floor uses this sheet for **sign-off**.

---

## Station tablet (shared login)

1. Tablet stays signed in as the **station** account.  
2. Do **not** sign into personal Google on the kiosk.  
3. Every sign-off: pick **your name** → enter **your PIN**.

Personal phone login: worker defaults to you; PIN still required.

---

## Sign off a checklist task

1. Open the **job** traveler / floor panel.  
2. Find the task (Machine / Fabrication / QA / Shipping).  
3. Tap to sign off.  
4. Select **worker**.  
5. Enter **floor PIN** (4–8 digits).  
6. Tap reason chip(s); add note if needed.  
7. Submit.

Viewers can sign off. Viewers still **cannot** edit the job.

## Office quick ref (not floor)

| Step | Who |
|------|-----|
| Upload WO PDF → Import traveler | admin / manager / member |
| Review Structure # / Fill N/A | same |
| Print · Email · Download DOCX | same (CRM + Traveler PWA) |
| Drawing packet (stamp / rotate / save) | same — **Drawing packet** on traveler |
| Re-import | New version; old traveler superseded |

### Drawing packet (office)

1. Open job traveler (CRM tab or `traveler.qbfab.com`).  
2. Tap **Drawing packet**.  
3. Select one or more drawing PDFs.  
4. Drag to place stamp; use **Stamp → All** if needed.  
5. Crop / margins / templates as needed for laminate holes.  
6. **Rotate** page or **Rotation → All** for print orientation.  
7. **Open / download PDF** to print, or **Save to Drive**.

## Quick fixes

| Issue | Fix |
|-------|-----|
| PIN rejected | Check worker name; ask admin to reset PIN |
| Wrong person on tablet | Use station account + picker, not shared personal login |
| Can’t edit job | Expected for viewer/station — sign-off only |
| No traveler on job | Ask office to import the work-order PDF |
